# Hangman Game 🎮

A simple text-based Hangman Game developed using Python as part of the CodeAlpha Python Programming Internship.

## 📌 Project Description

This project is a console-based Hangman Game where the player has to guess a hidden word one letter at a time. The player gets 6 chances to guess incorrect letters before the game ends.

## ✨ Features

- Random word selection
- User-friendly console interface
- 6 incorrect attempts allowed
- Displays guessed letters
- Win and Lose conditions
- Beginner-friendly Python code

## 🛠️ Technologies Used

- Python 3

## 📚 Concepts Used

- Random Module
- Lists
- Strings
- Loops (for, while)
- Conditional Statements (if-else)
- User Input Handling

## ▶️ How to Run

1. Download the project files.
2. Open terminal in the project folder.
3. Run the following command:

```bash
python hangman.py
```
